Matplotlib is the foundational Python library for data visualization.
In Data Science, it is used to visually explore, understand, and communicate data insights.

Think of Matplotlib as:

📈 The backbone of all Python plotting libraries
(Seaborn, Pandas plotting, and others are built on top of it)

1️⃣ Why Visualization is Important in Data Science

Before building ML models, a Data Scientist must:

Understand data distribution

Detect outliers

Find patterns & trends

Identify relationships between variables

📊 Visualization helps convert numbers into insights.

2️⃣ What is Matplotlib?

Open-source Python library

Mainly used for 2D plots

Provides full control over plot elements

Installation
pip install matplotlib

Import
import matplotlib.pyplot as plt

3️⃣ Basic Plot Structure

Every Matplotlib plot follows this flow:

plt.plot(x, y)
plt.xlabel("X Axis")
plt.ylabel("Y Axis")
plt.title("My First Plot")
plt.show()

4️⃣ Line Plot 📈 (Most Common)
Use Case

✔ Trend analysis
✔ Time-series data
✔ Stock prices

import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [10, 20, 25, 30, 40]

plt.plot(x, y, marker='o')
plt.title("Sales Growth")
plt.xlabel("Month")
plt.ylabel("Sales")
plt.show()

5️⃣ Bar Chart 📊
Use Case

✔ Category comparison
✔ Business reports

products = ["A", "B", "C"]
sales = [300, 500, 200]

plt.bar(products, sales)
plt.title("Product Sales")
plt.xlabel("Product")
plt.ylabel("Sales")
plt.show()

6️⃣ Histogram 📉
Use Case

✔ Data distribution
✔ Detect skewness & outliers

import numpy as np

data = np.random.randn(1000)
plt.hist(data, bins=30)
plt.title("Data Distribution")
plt.show()

7️⃣ Scatter Plot 🔵
Use Case

✔ Relationship between variables
✔ Correlation detection

x = [10, 20, 30, 40]
y = [15, 25, 35, 45]

plt.scatter(x, y)
plt.title("Height vs Weight")
plt.xlabel("Height")
plt.ylabel("Weight")
plt.show()

8️⃣ Box Plot 📦
Use Case

✔ Outlier detection
✔ Data spread analysis

data = [10, 12, 14, 15, 18, 100]
plt.boxplot(data)
plt.title("Outlier Detection")
plt.show()

9️⃣ Subplots (Multiple Graphs)
plt.subplot(1, 2, 1)
plt.plot([1,2,3], [3,2,1])
plt.title("Plot 1")

plt.subplot(1, 2, 2)
plt.bar(["A","B"], [10,20])
plt.title("Plot 2")

plt.show()


✔ Compare multiple insights at once

🔟 Customization (Very Important 🔥)
plt.plot(x, y, color='green', linestyle='--', linewidth=2)
plt.grid(True)


Customization options:

Colors

Line styles

Markers

Labels

Grid

Legends

plt.legend(["Sales"])

1️⃣3️⃣ Matplotlib vs Seaborn
Feature	Matplotlib	Seaborn
Control	Very High	Medium
Ease of Use	Medium	Easy
Styling	Manual	Built-in themes
Purpose	Base library	Statistical plots

👉 Learn Matplotlib first, then Seaborn.
